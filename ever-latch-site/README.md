# Ever Latch Website

Deploy-ready Vite + React site for Ever Latch Permanent Jewelry.

## Edit links
In `src/main.jsx`, replace:
- `https://example.com` with your booking link
- `https://instagram.com` with your Instagram link

## Edit carousel photos
In `src/main.jsx`, find `carouselPhotos` and replace the `src` image URLs.

## Vercel settings
Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
